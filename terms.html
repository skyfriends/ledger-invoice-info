Personal use

The Ledger is a personal local application for organizing account usage and original billing records. This website supplies information about that application and its Google connection; it offers no hosted invoice service or financial transactions.

Collection depends on a logged-in, available Mac, network access and valid mailbox authorization. Use original vendor documents to resolve billing questions. Google access can be revoked in the connected Google Account, and scheduled collection can be disabled in Ledger.
